Hosted CSV connector

Create and refresh company and regional revenue reports from a local MCP host. Five guided tools use the same hosted workflow as the browser.

Download Python script SHA-256 checksum

Use synthetic or nonsensitive CSV rows. The connector sends your CSV and exchange rates to hosted ProofFlow. ProofFlow runs the calculations without a model call. The MCP host may send tool inputs and outputs to its configured model.

Install in a local MCP host

Save both files in Downloads. From that folder, verify the script against its checksum.

cd "$HOME/Downloads"
shasum -a 256 -c proofflow_csv_mcp.py.sha256

Install uv. In Claude Code, replace the quoted example path with the location of your downloaded script.

claude mcp add --transport stdio proofflow-csv -- uv run --no-project --script "/absolute/path/proofflow_csv_mcp.py"
Configuration for other local stdio hosts 
{
  "mcpServers": {
    "proofflow-csv": {
      "command": "uv",
      "args": ["run", "--no-project", "--script", "/absolute/path/proofflow_csv_mcp.py"]
    }
  }
}

The script declares mcp==2.3.0 and httpx==0.28.1 and requires Python 3.11 or newer. You can inspect it before running it. It connects to this demo without a ProofFlow account, repository checkout, or HydraDB key.

Try a correction

Paste this synthetic task into your MCP host.

Use the ProofFlow Hosted CSV connector to create reports for NORTH with EUR → USD set to "1.20".

order_id,region,currency,gross_cents,refund_cents,ticket_count
n1,NORTH,EUR,10000,1000,3
s1,SOUTH,USD,20000,0,1

Save the generation and both report IDs from the create result. Call update_csv with rates {"EUR":"1.30"} and region "NORTH". Omit csv_text for this rate-only correction. Inspect both reports and attempt a checked export using the original IDs. Then refresh the reports and export using the fresh IDs. Show both totals and the actual refresh call count.

The initial totals should be $308.00 company and $108.00 NORTH. The correction withholds stale values and blocks the old export. After four recorded refresh calls, the checked snapshot should show $317.00 company and $117.00 NORTH.

Tools and session

  • create_csv_reports creates the two fixed revenue reports in the active session.
  • inspect_reports returns immutable IDs, claim currentness, and impact.
  • update_csv publishes corrected rows and rates. For a rate-only correction, omit csv_text and pass the existing region and all required rates.
  • refresh_reports recomputes affected work and returns actual execution counts.
  • export_current_reports checks the given generation and both report IDs, then returns plain-text snapshot content.

The connector keeps only the exact CSV text from the last confirmed create or update in memory. The host can omit that text from a later rate-only tool call in the same process. The connector checks the hosted session, workspace and CSV digest, then sends the cached bytes with the supplied rates. Provide the full corrected CSV when rows change.

If a write result is uncertain or the workspace reports an incomplete update, the connector discards its CSV cache. Start a fresh connector process and explicitly create reports with the intended CSV before changing or exporting reports again.

The one-week hosted demo shares capacity with browser sessions. Idle sessions expire after one hour. The connector keeps its session cookie in local process memory. Restarting clears the cookie and CSV cache. Explicitly create reports again to start a fresh CSV workspace. Creating again in the same process replaces the active import.
