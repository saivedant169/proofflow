# ProofFlow film: the build contract

How the parts plug together. The look is in `DESIGN.md`, every shot in `STORYBOARD.md`, the words in `research/script.md`. Run every command from `film/`.

## 1. What is fixed

- Canvas 1920 × 1080 CSS px, 30 fps. Final render 3840 × 2160 (device scale 2): one CSS px = two output px.
- `timing.json` holds the eight section windows; it is generated by `node tools/plan-timing.mjs` from the measured narration. A section file's root `data-duration` must equal its window (sync fails otherwise). Windows can move when narration is re-fitted — you never hard-code seconds, so that costs you nothing.
- **Run `node tools/sync.mjs` before every preview, snapshot or lint.** It validates and writes `film-data.js` and updates `index.html` mounts.
- `index.html`, `film.css`, `film.js` belong to LEAD. Ask for a token or helper in your report; do not edit them and do not copy them.
- Cuts between sections are hard cuts on the one ground `--ground`. Where STORYBOARD says a section's last frame is the next one's first, both files draw that frame.

## 2. A section file

Copy the shape of `compositions/_template.html`. Rules that break silently if ignored:

1. Everything lives inside one `<template>`: `<style>`, the root `<div>`, `<script>`. The file's `<head>` is dropped.
2. Root: `<div id="root" data-composition-id="<composition id>" data-width="1920" data-height="1080" data-duration="<window seconds>">`, styled by `#root { position:absolute; inset:0; overflow:hidden; background: var(--ground) }`. Never style the root by a class.
3. Every other id and class starts with your section id (`s4-…`): all sections share one page.
4. One paused GSAP timeline, registered last: `window.__timelines["<composition id>"] = tl;`. Timeline time 0 = the section's start. The section holds its last frame until its window ends.
5. Link nothing. `film.css`, GSAP (`gsap`) and `FILM` are already on the page. No CDN, no fetch, no `Date`, no unseeded `Math.random`, no `repeat: -1`.
6. Animate with `tl.fromTo()` (both ends stated), never `from()`. Never set a CSS `transform` on an element you also tween with `x`, `y`, `scale` or `rotation` (use `xPercent/yPercent` in the tween for centring). Do not tween `visibility` or `display`.
7. Colours, fonts and type sizes come from `film.css` tokens/classes only (`var(--ink)`, `.t-head`, `.node`, `.fig`, …). Write `font-family: var(--font-display|--font-sans|--font-mono)`, never a family name. No hex in section files.
8. Everything must stay razor sharp: no `filter: blur`, no glow, no grain, no vignette, no darkening overlay or scrim, no watermark. Never scale a still above its native pixels (`FILM.mountStill` enforces it); never scale text up through a big `scale` tween from small (animate it at its final size).
9. Positions passed to `FILM` helpers and `tl` must be numbers (seconds from the section start), e.g. from `FILM.at()`.

## 3. Narration word times (generated; never read the JSON yourself)

`audio/words.json` is measured from the real narration. Use `FILM`:

| Call | Gives |
|---|---|
| `FILM.at("s2", "context")` | seconds from the section start to that word (case/punctuation ignored); multi-word runs allowed |
| `FILM.at("s4", "rate", 2, -0.1)` | the 2nd "rate", 0.1 s early |
| `FILM.atEnd("s1", "report")` | at the word's end |
| `FILM.line("4d")` | `{ start, end, text, localStart, localEnd }` — use `localStart` / `localEnd` |
| `FILM.mark("correction", "s4")` | named marks: `name` (s3 "ProofFlow takes…"), `correction` (line 4d), `run` (s6's unnarrated run window), `finalName` (s8) → `{ localStart, localEnd }` |
| `FILM.section("s6")` | `{ start, duration, end }` film seconds — `duration` is your window |

A word that is not spoken throws at load, so a typo fails loudly. Numbers are spoken as words ("thirty-two", "sixty-nine").

## 4. Motion helpers (film.js)

- `FILM.drawThread(tl, pathOrSelector, at, { duration, reverse, ease })` — draws an SVG stroke on.
- `FILM.pulseAlong(tl, path, dot, at, { duration, reverse, scale, offset })` — moves a `.pulse` dot along a path (dot and path's svg share the same positioned parent; the `.threads` svg is 1920×1080 at 0,0, so no scale/offset is needed when both sit in the root or the same world layer).
- `FILM.countTo(tl, el, from, to, at, { duration, format })` — count a figure.
- `FILM.withhold(tl, figEl, at)` / `FILM.restore(tl, figEl, at)` — the `.fig` narrows on Anybody's width axis, dims and shows its `.withheld-hatch`; restore reverses.
- `FILM.speakWords(tl, el, sectionId, { lead, rise, nth })` — kinetic type: reveals each word of an element on its spoken time (every word must be spoken in that section).
- `FILM.outline(tl, parent, rect, at, { grow, radius })` — draw-on highlight; add class `stale`/`fresh` to the returned svg for state colour.
- `FILM.mountStill(el, stillId, { width, box, pad, maxScale })` — product stills (s5); returns `{ k, rect(boxName) }`.
- `FILM.ease` ("power3.out") and `FILM.move` (0.7 s) are the house move.

## 5. Product stills: `stills/` + `stills/stills.json`

Written by CAPTURE. `node tools/sync.mjs --list` prints what can be mounted, how wide, and the named boxes. A full frame is `pNN-slug`; crops are `pNN-slug.name`.
