# Dataset attribution

Chen, D. (2015), Online Retail, UCI Machine Learning Repository, https://doi.org/10.24432/C5BW33, licensed CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.

All eligible positive transaction lines on the declared dates are retained. Numeric spreadsheet cells follow the fixture's explicit normalization policy; line totals are exact integer GBP pence. Cancellations and invalid/bounded-out rows are excluded. CustomerID/product descriptions are omitted; original row identities and numeric XML provenance remain. Refunds, FX rates and corrections are authored evaluation inputs, not observed historical errors. This is not a complete merchant ledger. No original dataset endorsement is implied.
